# 测试目录索引

`tests/` 存放根应用层和工作区公共行为的集成测试、回归测试与结构约束测试。

## 当前测试类型

- 渲染器与字段组件行为测试
- DataKey、DataView、CRUD 桥接回归测试
- 路由、导航、权限、协议对齐测试
- 公共导出面与目录结构约束测试

## 目录约定

- `helpers/`：测试挂载与上下文注入辅助函数。
- `*.test.ts`：按能力域命名，优先体现行为或回归目标，而不是实现细节。

## 编写原则

- 运行时公共约束优先在这里守住，避免只靠手工回归。
- 新测试文件命名应能直接体现覆盖范围，例如 renderer、permission、navigation、stills。
- 包内专属测试继续放在各自包目录；跨包行为和根应用集成测试放这里。

## 常用命令

```bash
pnpm run test
pnpm run test:run
```
