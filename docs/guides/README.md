# 使用指南索引

这个目录只放当前仍然可执行的使用文档。

## 推荐顺序

1. [QUICKSTART.md](QUICKSTART.md)：安装、启动、ProjectModel / PageNode 最短认知。
2. [CONFIG_SYSTEM.md](CONFIG_SYSTEM.md)：应用启动配置与项目/页面节点模型配置边界。
3. [DATA_MANAGEMENT.md](DATA_MANAGEMENT.md)：DataSet、DataView、绑定与联动。
4. [TREE_CAPABILITY.md](TREE_CAPABILITY.md)：树形场景、treeMode 与后端树 API。

## 常用专题

- [COMPONENT_DEVELOPMENT.md](COMPONENT_DEVELOPMENT.md)：新增或维护组件。
- [PLUGIN_CONFIGURATION.md](PLUGIN_CONFIGURATION.md)：插件接入与启停。
- [CONDITION_EXPRESSION.md](CONDITION_EXPRESSION.md)：过滤表达式与计算表达式。
- [SAVE_DATASET_ACTION.md](SAVE_DATASET_ACTION.md)：声明式保存动作。
- [TESTING_BEST_PRACTICES.md](TESTING_BEST_PRACTICES.md)：前端测试编写方式。
- [PERFORMANCE_GUIDE.md](PERFORMANCE_GUIDE.md)：性能分析与优化策略。
- [CACHE_EXPIRATION_TIERS.md](CACHE_EXPIRATION_TIERS.md)：缓存分层与失效模型。

## 维护约束

- 新增指南必须能对应一个当前可执行场景。
- 不再引用 blog-series。
- 不再引用不存在的指南。
- 涉及页面配置时，统一使用 `ProjectModel`、项目节点树、`PageNode` 和四文件投影的术语。
