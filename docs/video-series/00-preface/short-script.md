# 第 00 集短视频稿：序篇

目标时长：90-180 秒  
短视频标题：为什么 SPARK_VIEW 值得拆成 16 篇？

## 口播稿

如果你以为 SPARK_VIEW 是一个 JSON 表单项目，这个系列会把这个误会拆掉。

真实后台页面不是字段加按钮。它有主从表、树数据、聚合、权限、路由、实时预览、版本回滚，甚至还要让 AI 安全地参与修改。

所以 SPARK_VIEW 的核心不是“少写 Vue”，而是把页面变成可治理的软件资产。

这 17 集会按一条主线展开：四文件协议如何定义资产，Renderer 如何解释页面，DataSet 如何管理数据，权限为什么只是前端装饰，AI Runtime 为什么必须是通用受约束架构，DevSystem 又如何把这一切接成生产闭环。

想快速看全局，先看第 1、2、7、10、13、14、16 集。完整源码链路看本系列长视频。
